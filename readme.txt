Theme WordPress ringan untuk portal berita: cepat, responsif, ramah mesin pencari, tanpa page builder dan tanpa framework frontend besar.

== Description ==

hakanews dirancang untuk portal berita berbahasa Indonesia. Halaman depan menyusun artikel dalam blok berita utama, kategori pilihan, dan daftar terbaru. Tampilan artikel dilengkapi daftar isi otomatis, tombol bagikan tanpa skrip pihak ketiga, dan artikel terkait. Semua pengaturan tampilan ada di Customizer dan berubah langsung di pratinjau.

Theme ini hanya memuat CSS, JavaScript, dan font yang dibundel di dalam theme. Tidak ada jQuery di sisi pengunjung, dan secara bawaan tidak ada permintaan ke layanan pihak ketiga. Google Fonts tersedia sebagai pilihan yang dinyalakan sendiri.

== Installation ==

1. Di dashboard WordPress buka Tampilan > Tema > Tambah Baru.
2. Klik Unggah Tema, pilih berkas zip hakanews, lalu klik Pasang Sekarang.
3. Klik Aktifkan.
4. Buka Tampilan > Sesuaikan untuk mengatur logo, warna, font, dan tata letak halaman depan.

== Frequently Asked Questions ==

= Apakah theme ini butuh plugin tertentu? =

Tidak. Semua fitur berjalan tanpa plugin tambahan. Bila plugin SEO atau plugin cache aktif, theme mengenalinya dan menyesuaikan keluarannya agar tidak ganda.

= Apakah bisa dipakai untuk blog biasa? =

Bisa. Blok berita di halaman depan opsional; tanpa pengaturan tambahan theme menampilkan daftar artikel terbaru seperti blog pada umumnya.

= Apakah mendukung child theme? =

Ya. style.css theme dimuat lebih dulu, lalu stylesheet utama di assets/css/main.css, sehingga child theme dapat menimpa keduanya.
